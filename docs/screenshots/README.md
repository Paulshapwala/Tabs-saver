# Screenshot context — 12 November 2026

All images in this directory are unretouched browser captures of a **local demonstration using synthetic data**. No real browsing history, production database, physical sensor feed or hosted deployment is represented.

- `tabs-saver-saved-topics.png`: existing JavaScript interface lists sample topics returned by Flask/SQLite.
- `tabs-saver-retrieved-links.png`: selecting a sample topic retrieves saved public GitHub links. The capture is clipped to include the complete small interface.

These show a local web preview of the extension interface. A temporary backend substituted a writable local database path for the hard-coded Windows path and served the existing frontend files. That setup adjustment is not included here. Browser extension installation, tab capture and reopening were not tested. The visible “Open All Tabs” control is not evidence of a successful reopen operation.
